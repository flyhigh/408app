## 🤖 Assistant

下面给你的是**只包含 5 个底部 Tab 首页**的  
**Figma 导航线框文稿版**，可以直接交给 UI / 交互设计师开画原型。

我这版是基于你当前产品主链路做的：首页必须服务于  
**计划 → 执行 → 复习 → 错题 → AI → 长期配置**。

同时，这版首页结构不是凭空想的，而是参考了 Refero 里的真实 iOS 页面模式：

- **今日/任务首页参考**：Planny、Todoist  
  结论：高频首页最稳的是**大标题 + 进度摘要卡 + 分组列表 + 明确主 CTA**
- **知识库/学习首页参考**：MasterClass、WURRD、LookUp  
  结论：最稳的是**搜索前置 + 分类卡片 + 继续学习/最近学习**
- **复习首页参考**：LookUp、CapWords、Kann  
  结论：最稳的是**复习统计卡 + 到期列表 + “开始批量复习”主按钮**
- **AI 首页参考**：Raycast、ChatGPT  
  结论：最稳的是**快捷场景卡 + 最近会话 + 固定输入入口**
- **我的首页参考**：Mailchimp、1Password  
  结论：最稳的是**用户信息卡 + 当前目标卡 + 分组设置列表**

另外我也用其他 MCP 做了补充校验，结论没有和 Refero 的结构判断冲突：  
**移动端首页一定要“一个主任务 + 少量次级入口”，不能首屏堆太多内容。**

# 十、这一版首页线框的核心原则

你这款 App 的首页不能像普通知识 App 那样做成“内容发现页”，  
也不能像通用 AI 那样做成“一个输入框”。  
它的首页体系应该是：

- **今日首页**：管执行
- **知识库首页**：管查找与继续学习
- **复习首页**：管闭环
- **AI 首页**：管卡点求助与智能调度
- **我的首页**：管长期约束与系统设置
